## 🧭 The 6 Strict Rules for Every Agent

1. **Zero Entity Exposure**:
   - NEVER accept or return an Entity in an Application Service or API.
   - ALWAYS use dedicated DTOs (`ProductDto`, `CreateProductDto`, `UpdateProductDto`, `GetProductListInput`).
2. **Zero Reinvention (DRY with ABP)**:
   - Do NOT create custom tables/entities for Users, Roles, Permissions, Tenants, or Settings.
   - Do NOT write manual `Skip`/`Take` logic; use `.PageBy(input)` and `PagedResultDto<T>`.
   - Do NOT write manual `if` cascades for LINQ; use `.WhereIf(...)`.
   - Do NOT write manual controllers for CRUD; use ABP Auto API Controllers.
   - Do NOT write manual try/catch blocks; let ABP Exception Filters handle exceptions via `UserFriendlyException` or `BusinessException`.
3. **Arabic XML Summaries**:
   - Every class, method, parameter, and property MUST include clear `/// <summary>` comments in Arabic.
4. **SOLID Enforcement**:
   - SRP: Entities protect invariants; AppServices orchestrate; DomainServices (Managers) handle cross-entity business rules; Configurations handle EF Core mappings.
   - DIP: Always use constructor dependency injection (`IRepository<T, TKey>`, `IProductManager`, `IObjectMapper`).
5. **Feature-Driven Isolation**:
   - Every feature (e.g., `Products`) has its own folder in each layer (`Domain.Shared`, `Domain`, `EntityFrameworkCore`, `Application.Contracts`, `Application`).
   - One class per file.
6. **Explicit AutoMapper Profiles**:
   - Never rely on implicit conventions. Map DTOs explicitly and ignore autogenerated fields (`Id`, `TenantId`).
7. **Clean File Upload Architecture (`IFormFile`)**:
   - `IFormFile` is an HTTP Web abstraction; it belongs EXCLUSIVELY in upload DTOs in `Application.Contracts` or `HttpApi`.
   - Domain Entities MUST NEVER reference `IFormFile` or `Microsoft.AspNetCore.Http`. Store file metadata (`FileName`, `ContentType`, `PublicUrl`, `BucketName`, `ObjectKey`) in Entities.
8. **Mandatory `#region` Code Organization**:
   - Always group and organize class members using standardized `#region` blocks (`#region Properties`, `#region Constructors`, `#region Methods`, `#region Navigation Properties`) for clean folding in IDEs.

## 🛠️ Feature Implementation Checklist for the Agent

When asked to create or modify a feature (e.g., `Products`, `Orders`, `Customers`), execute these steps in strict sequence:

### Step 1: `Talabi.Domain.Shared`
- Create `src/Talabi.Domain.Shared/[Feature]/[Feature]Consts.cs` (string lengths, regex patterns).
- Create enums if needed.
- Add Arabic/English localization keys in `Localization/Talabi/ar.json` and `en.json`.

### Step 2: `Talabi.Domain`
- Create `src/Talabi.Domain/[Feature]/[Feature].cs` inheriting from `FullAuditedAggregateRoot<Guid>` and implementing `IMultiTenant` (if tenant-scoped).
- Add private setters and business constructors to protect entity invariants.
- If complex validation across tables is needed, create `[Feature]Manager.cs` (inheriting from `DomainService`).

### Step 3: `Talabi.EntityFrameworkCore`
- Create `src/Talabi.EntityFrameworkCore/EntityConfigurations/[Feature]/[Feature]Configuration.cs` implementing `IEntityTypeConfiguration<T>`.
- Configure table name, max lengths, indexes, and precision. Call `builder.ConfigureByConvention()`.
- Register the configuration in `TalabiDbContext.cs`.

### Step 4: `Talabi.Application.Contracts`
- In `src/Talabi.Application.Contracts/[Feature]/Dtos/`:
  - `[Feature]Dto.cs` (inherits from `AuditedEntityDto<Guid>`).
  - `Create[Feature]Dto.cs` (with DataAnnotations in Arabic).
  - `Update[Feature]Dto.cs`.
  - `Get[Feature]ListInput.cs` (inherits from `PagedAndSortedResultRequestDto`).
- In `src/Talabi.Application.Contracts/[Feature]/`:
  - `I[Feature]AppService.cs` (inherits from `ICrudAppService<...>` or `IApplicationService`).
- Define permissions in `Permissions/TalabiPermissions.cs` and `TalabiPermissionDefinitionProvider.cs`.

### Step 5: `Talabi.Application`
- Create `src/Talabi.Application/[Feature]/[Feature]AutoMapperProfile.cs` (inheriting from `Profile`).
- Create `src/Talabi.Application/[Feature]/[Feature]AppService.cs`:
  - Inherit from `CrudAppService` or `ApplicationService`.
  - Apply `[Authorize(TalabiPermissions.[Feature].Default)]`.
  - Add structured Serilog logging using `Logger.LogInformation(...)`.

## 🚨 Anti-Patterns & Verification
Before marking any task as complete, the agent MUST verify:
- [ ] No compilation errors (`dotnet build` succeeds).
- [ ] No `try { ... } catch { return error; }` in AppServices.
- [ ] No direct LINQ `Where(x => x.TenantId == ...)` (ABP handles it automatically).
- [ ] No missing Arabic `<summary>` tags.
- [ ] No missing AutoMapper profile.
